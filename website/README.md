# 無料公開向け静的版

Rails版を残したまま、GitHub Pagesなどで公開できるHTML/CSS/JavaScript版を置いています。

## できること

- 11/1 LAND・11/2 SEAの選択と戻る操作
- やりたいことの追加、達成チェック、削除、進捗表示
- 4桁PIN画面と15時間後の再ロック
- チェック項目とPINのブラウザ保存

## データ保存とPINについて

データは使っているブラウザの`localStorage`に保存されます。同じブラウザ内ではページを閉じても残りますが、別のiPhoneや別ブラウザとは同期しません。ブラウザのデータを消すと、PINとチェック項目も消えます。

PINは画面を開くときの簡易ロックです。静的サイトではサーバー側の本人確認ができないため、アクセス制御や秘密情報の保護には使えません。GitHub Pagesの公開URLとソースコードは公開状態になります。

## ローカルで見る

`index.html`をブラウザで開きます。GitHub Pagesで公開する場合は、GitHub Actionsを使ってこのフォルダの内容を公開します。GitHub Pagesのブランチ指定では任意のフォルダを直接選べないためです。
