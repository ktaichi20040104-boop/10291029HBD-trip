# HBD Mizusa static trip app

A static HTML/CSS/JavaScript edition of the trip checklist, published with GitHub Pages.

Live site: https://ktaichi20040104-boop.github.io/10291029HBD-trip/

The app code is public. PIN and checklist data are saved only in each browser's local storage and do not synchronize across devices. The PIN is a convenience lock, not server-side authentication.

See `website/README.md` for app behavior and local use.
